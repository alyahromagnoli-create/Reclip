# Reclip｜回拾 1.0.0

用本次新安装的 PyQt6 6.12.0 制作的 Windows 剪贴板时间机器。

## 开始使用

双击 Reclip.exe，默认 Alt+V 呼出浮窗。首次解包需几秒。窗口顶部显示实际注册的热键；Alt+V 被占用时会提示，软件不会自行改绑其他组合；可在“设置”自定义。Ctrl+Q 已保留给 QQ，不会注册。

程序运行后，复制文本或图片会记录在本地。为了不擅自收集启动前的内容，启动时不会抓取已经存在的剪贴板内容。最多保留最近 50 条；完全相同的内容再次复制会移至最前并增加复制次数。空内容忽略，文件列表不作为文本记录。

1. 在要粘贴的输入框里放好光标。
2. 按热键呼出 Reclip。
3. 点击一条历史，软件会收起浮窗并向原窗口发送 Ctrl+V。

也可以用上下键选择、Enter 回贴，Esc 收起。右键条目可以只复制、预览、处理或删除。首次直接从程序窗口启动且没有原目标窗口时，点选只复制到剪贴板，并显示提示。

收起或关闭窗口会留在系统托盘；窗口“退出”按钮或窗口“退出”按钮或窗口“退出”按钮或托盘菜单的“退出”才会结束记录。默认不设置开机启动，也不会替换系统 Win+V。

## 文字工具

- 纯文本：去掉剪贴板格式、零宽字符和不可见控制字符，统一换行、清理行末空格和多余空行。
- 提取网址：识别 http、https、www 开头的网址，去重，每行一条；www 自动补 https://。
- 提取邮箱：识别常见电子邮箱，去重，每行一条。
- 结果在可编辑预览中显示，可复制为纯文本或粘贴回原窗口。处理结果不会自动新增一条历史，避免自己操作造成循环记录；需要保留时可再次在外部复制。
- 在线翻译：确认后将当前这一条文字打开到 Bing 翻译网页，默认目标中文。最多 5000 字，需要网络；没有内置离线全文翻译或付费 AI API。其他历史不会发送，自动测试没有向翻译服务提交文本。

点击条目会立即回贴；需要先选中再使用底部文字工具时，可用上下键选择，或右键条目使用处理菜单。

## 图片与回贴限制

图片以 PNG 存入 SQLite。单条图像 PNG 上限 20 MiB、像素上限 4000 万；文本上限 1 MiB，超限会跳过并提示。不是图片编辑器，不记录文件对象和所有富文本格式。

自动粘贴使用 Windows 原生输入机制。程序会确认原窗口仍存在且已恢复到前台后才发送；失败则保留在系统剪贴板中，提示手动 Ctrl+V。目标软件必须支持相应内容：有些纯文本编辑器不能粘贴图片，管理员权限窗口、游戏或特殊输入控件也可能限制模拟输入。程序不会自动申请管理员权限。

热键使用 Windows RegisterHotKey，没有全键盘监听；文本和图片由 Qt 剪贴板接口读取，因此不再需要 pyperclip 或 keyboard 完成这些相同职责。

## 数据与暂停

学习用内容以外，真实复制内容可能含私人信息。本地历史没有加密，程序没有账号或云同步。暂停记录后可继续使用旧历史。可删除单条或清空全部历史；清空历史不清空系统剪贴板当前内容。识别到应用设置的 Windows 排除监控标记时会跳过，但不能承诺识别所有密码应用。

## 当前便携版

本版本不要求 D 盘。程序运行库包含在单个 EXE 内，使用系统临时目录解包，数据保存到 EXE 旁的 data。只读目录请先移动到可写位置。原有个人记录需要一并复制 data，发布包不含个人数据。
